Quantile forecast of Grand Theft Auto VI's concurrent Twitch viewers for every hour of its release day (2026-11-19 UTC), made from hour 1's print.

How it works: each past launch in the case's comparables gives a release-day curve of log ratios to its own hour 1. The analogues are weighted by how much they resemble this launch at the end of hour 1 (momentum: the previous 24 hours' peak against hour 1; scale: the size of hour 1; early-access launches count less), and each hour's five quantiles are the weighted, kernel-smoothed quantiles of those ratios times hour 1's print. Node 22, standard library only, deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
